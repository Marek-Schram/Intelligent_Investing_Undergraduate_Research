# Research bulletins

One directory per quarter: `YYYY-QN/` with metrics.json, returns.csv, attribution.csv,
positions.csv, factor_ic.csv, tables/*.tex, figures/*.png, methodology.md.

**Committed and never edited after the fact.** A wrong number gets a corrected bulletin with a
new timestamp rather than rewriting history. That rule is what makes this directory usable as
evidence.
